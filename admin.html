Entrar

Para guardar cambios en tu catálogo necesitas tu llave de GitHub. Solo sirve para el repositorio del catálogo.

¿Cómo saco mi llave?
  1. En GitHub abre Settings › Developer settings › Personal access tokens › Fine-grained tokens y toca Generate new token.
  2. Resource owner: miniprintsmx. Repository access: Only select repositories › miniprintsmx.github.io.
  3. Permissions › Repository permissions › Contents: Read and write. Nada más.
  4. Genera la llave, cópiala y pégala aquí. Guárdala en un lugar seguro: GitHub solo la muestra una vez. Las llaves vencen: cuando pase, aquí te avisará y sacas una nueva igual.
